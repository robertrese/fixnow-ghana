FixNow Ghana Privacy Policy

Effective date: July 15, 2026

FixNow Ghana can create a server-confirmed report when the configured API is available. A report first remains on the device if the service cannot be reached. After confirmation, the app provides a report reference and private tracking secret; both are required to view the report from another device.

Data stored locally

  • Report category, severity, details, status, district, region, community, and estimated people affected.
  • Optional GhanaPostGPS address, optional GPS coordinates, optional reporter contact, and optional photo evidence.
  • Language, accessibility, consent, and display preferences.

Permissions

Location is requested only when the user taps "Use current GPS." Photo access is requested only when the user chooses a photo. The app does not require contacts, SMS, call logs, payment information, advertising identifiers, or background location.

Sharing

When a citizen confirms submission, the report is sent to the FixNow API and stored in its database. Public tracking returns only the report reference, general area, status, and responder public updates. It never returns reporter contact details, trusted contacts, precise GPS coordinates, or private responder notes. Authenticated responders receive access only for their permitted operational area. Users can also copy a brief, open a WhatsApp share link, or export CSV/JSON; once shared or exported, the receiving app or recipient controls that copy.

Retention and deletion

Reports stay on the device until the user deletes local data or clears browser/app storage. The in-app "Delete local data" action removes reports, consent state, and local settings from that device; it does not delete a confirmed server report. The owner must establish public server-side retention, deletion, and anonymisation periods before production launch.

Security

The API uses authenticated responder sessions, role and operational-area checks, audit logging, request rate limits, and no-store API responses. Public submission and private tracking are implemented. Secure attachment handling, a public deletion process, final retention rules, a data controller, and a published incident-response process remain required before production launch.

Contact

Data controller: To be appointed by the owner before launch. Privacy contact: To be configured before launch. Deletion request process: The owner must publish a monitored request channel before production launch. Breach/reporting process: The owner must publish a monitored reporting channel and incident-response procedure before production launch.
