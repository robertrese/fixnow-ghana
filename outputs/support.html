FixNow Ghana Support

This build is not accepting public production reports. A monitored support email, organization name, escalation hours, and deletion-request process must be configured before launch.

Emergency contacts

  • Use the verified emergency contacts in FixNow for life-threatening danger. The app asks for confirmation before opening your dialler.

In-app help

  • Use the language help strip for simplified guidance in English, Twi, Ga, Ewe, and Hausa.
  • Use Large text, High contrast, Simple mode, and Read help for accessibility support.
  • Use Export CSV/JSON before deleting local data if you need a copy.

Demo and support configuration

For review only, append ?demo=1 to the app URL. Demo reports use separate browser storage and server sync is disabled. Production starts without sample reports.

Support email: not configured. Data controller: to be appointed. Privacy/deletion requests: no public channel is active until the public service is implemented. The owner must configure these contacts, retention periods, and breach-reporting process before launch.
