# Apple App Store Release Checklist

Generated: June 21, 2026

Apple release cannot be completed on this Windows workspace alone. It requires macOS, Xcode, an Apple Developer Program account, and App Store Connect access.

## Required Account Work

- [ ] Enroll in Apple Developer Program.
- [ ] Create App Store Connect app record.
- [ ] Create Bundle ID.
- [ ] Create signing certificate and provisioning profile.
- [ ] Build iOS app with Xcode or approved CI.
- [ ] Upload build through Xcode, Transporter, or App Store Connect workflow.

## App Review Information

- [ ] Demo responder account for reviewer.
- [ ] Explanation of civic reporting purpose.
- [ ] Privacy policy URL.
- [ ] Support URL and support email.
- [ ] Notes explaining that public reports hide sensitive identity/location by default.
- [ ] Age rating.
- [ ] App Privacy answers.
- [ ] Accessibility Nutrition Labels review if used.

## TestFlight First

- [ ] Internal TestFlight with team.
- [ ] External TestFlight with limited Ghana pilot group.
- [ ] Test VoiceOver, Dynamic Type, low connectivity, one-handed reporting, and old device performance.
- [ ] Fix all blocker feedback before App Review submission.
